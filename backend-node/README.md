# backend-node

Node.js backend untuk Chat App. Dokumentasi lengkap ada di [root README](../README.md).

## Quick Start

```bash
npm install
cp .env.example .env
npm start        # production
npm run dev      # development (nodemon)
```

## Environment

```env
PORT=8080
BASE_URL=http://localhost:8080
NODE_ENV=development
```

Lihat [ENV.md](./ENV.md) untuk detail konfigurasi per platform deploy.
